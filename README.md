# 🏙️ Buenos Aires Housing Market Analysis

This project was completed as part of the **Applied Data Science Lab** by **WorldQuant University**. It explores housing price trends in Buenos Aires using real-world data and predictive modeling techniques.

## 📌 Objective
To analyze and model housing data from Buenos Aires, uncovering key factors that influence pricing, and building a regression model to predict housing costs.

## 🧰 Tools & Libraries
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Jupyter Notebook

## 🗃️ Dataset
The dataset contains information on properties in Buenos Aires, including:
- Location (neighborhoods)
- Property type
- Surface area (total and covered)
- Number of rooms
- Price in USD

## 🔍 Workflow
1. **Data Cleaning**  
   - Removed outliers and missing values  
   - Transformed categorical variables  

2. **Exploratory Data Analysis (EDA)**  
   - Distribution of housing prices  
   - Price per square meter by neighborhood  
   - Correlation heatmaps  

3. **Modeling**  
   - Built and evaluated regression models (Linear Regression, Random Forest)  
   - Compared performance using RMSE and R²  

4. **Key Results**
   - Random Forest gave the best performance with an R² of 0.87  
   - Location and surface area were the most important features

## 📈 Visualizations
Visuals include:
- Price trends per neighborhood  
- Scatter plots for price vs. surface  
- Feature importance chart from Random Forest
